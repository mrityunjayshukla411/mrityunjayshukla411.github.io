## What I worked on

## Key Insights
- In triton each version is bound to a specific commit hash in the LLVM project and this
commit hash is stored in the `cmake/llvm-hash.txt` file in the `triton` library.
- The exact commit hash can also be found out using `libtriton.so` with the command
`strings libtriton.so | grep -E "LLVM.*git|clang.*git|llvmorg"`
